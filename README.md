# 📝 Selected works

## 🌪️ Extreme Event Attribution &amp; Climate Modeling

* **Extreme Event Attribution of the 2025 Sumatra Flash Floods associated with Tropical Cyclone Senyar**
    * **[Trend Detection in Extreme Precipitation](https://github.com/nathasya-abenita/diploma_data_analysis)** \
    Applied non-stationary extreme value theory to evaluate area-averaged 5-day extreme rainfall (Rx5day) against Global Mean Surface Temperature (GMST) trends. 
    * **Physical-Based Attribution** \
    Applied pseudo-global warming method (PGW) to evaluate Tropical Cyclone Senyar and precipitation across different climate states using the high-resolution regional climate model RegCM5 forced by ERA5.

## 🛠️ Climate &amp; Geospatial Data Tools 

* **[BMKG Meteorological Data Toolbox](https://github.com/nathasya-abenita/bmkg_data)** \
Developed a Python toolbox to clean, pre-process, and convert publicly available daily station Excel files from the Indonesian Meteorological, Climatology, and Geophysical Agency (BMKG) into standardized NetCDF datasets.
* **Python Flood Damage &amp; Risk Calculator** \
Created Python-based spatial analysis tools to map flood depth and land-use data into socio-economic damage costs and risk profiles.
